# 探针设计与结论（汇报整理稿）

> 本文整理自组内汇报笔记中的「我的探针（Route B，softmax 软超边版）」一节，
> 保留原始设计与结论，补充重建说明。

## 一、探针设计

- **目的**：判断"SSM 隐状态驱动超图"这一路线 B 核心主张是否成立。
- **设计**：3000 步 ≈ 10 epoch（301 步/epoch）的**漏斗式方向筛选**；
  **只判方向、不判有效性**。
- **做法**：**四源消融**，唯一变量 = 超边归属矩阵 `H` 的输入。
- **一致性**：四份配置跑在同一训练协议下——同一脚本 `train_pedro_baseline.py` + 同一 LR 0.01。

| 源 | `H` 的输入 | 含义 |
|---|---|---|
| `ssm` | SSM 隐状态 `h_ssm` | 路线 B 原始主张 |
| `semantic` | 图特征 `data.x` | 通用特征基线 |
| `motion` | 位置/时间 `[x,y,t]` | 物理先验 |
| `joint` | `ssm + semantic + motion` | 联合 |

**机制**：softmax 软超边（**无硬选择**）+ 门控残差 + 三项软正则
（entropy 0.02 / sharpness 0.02 / consistency 0.1）。

> 对照的 `ssm2hg-v1` 候选版是**串行**结构：`H = AdaptiveHyperedge(h_ssm)`，
> 即超边归属矩阵由 SSM 隐状态导出。**四源消融正是围绕这一个接口做替换。**

## 三、结果（epoch5 ≈ 1505 步；全部 val 指标）

| 源 | epoch0 mAP | epoch5 mAP | AP50 | AP75 |
|---|---:|---:|---:|---:|
| B0（对照） | .2209 | .4090 | 未记录 | 未记录 |
| `ssm` 探针 | .1978 | .3998 | .8241 | .3093 |
| **`semantic` 探针** | .1828 | **.4220** | .8269 | .3644 |

**mAP（epoch5）**：`semantic` .4220 > B0 .4090 > `ssm` .3998

- `semantic` − `ssm` = **+2.22pp**
- `semantic` − B0 = **+1.30pp**
- `ssm` − B0 = **−0.92pp**

**AP50 / AP75（epoch5）**：B0 未记录，只能 `ssm` 与 `semantic` 对比

- AP50：`.8269` vs `.8241` → 差 **+0.28pp**，基本持平（检出目标数量不变）
- AP75：`.3644` vs `.3093` → 差 **+5.51pp**，明显提升（框贴得更紧）

→ **增益指纹**：AP50 平 + AP75 大涨 = **定位收紧**，而非检出更多目标。

## 四、结论

1. 超边操作有**早期正信号**（`semantic` +1.30pp）。
2. **SSM 隐状态是坏来源**（比 `semantic` 低 2.22pp、比 B0 低 0.92pp）
   → **路线 B 核心主张在软超边版被否定**。
3. 应转向 **`semantic` / `motion` 驱动超边**。

### 汇报措辞（诚实版）

> 在软关联（softmax 软超边）+ 门控残差版本下，SSM 隐状态作为超边归属来源，
> epoch5 已低于语义特征来源 2.22pp（AP75 差 5.5pp）、低于无超边 B0 基线 0.92pp。
